# gpc_bot

Telegram-бот: ссылка → пост в канал.

Бот реагирует на **тег (упоминание) со ссылкой** в чате (в т.ч. в приватном чате,
привязанном к каналу), а также на ссылки в личке и команду `/post <ссылка>`.
Из ссылки собирается короткий пост — **картинка + название + ссылка** — и публикуется в канал.

## Файлы
- `bot.py` — логика бота (Telegram Bot API, python-telegram-bot)
- `link_parser.py` — загрузка страницы, извлечение `og:title` / `og:image` / описания
- `config.py.example` — шаблон настроек (токен + ID канала)
- `requirements.txt`

## Установка и запуск
```bash
pip install -r requirements.txt
cp config.py.example config.py   # заполнить BOT_TOKEN и CHANNEL_ID
python bot.py
```

## Как настроить
1. Создайте бота у @BotFather -> получите токен -> впишите в `config.py`.
2. Добавьте бота **администратором** в канал `gpc_test_chanel` с правом публикации сообщений.
3. Узнайте ID канала:
   - для публичного можно указать `"@gpc_test_chanel"`;
   - для приватного — числовой ID вида `-100XXXXXXXXXX`. Проще всего: перешлите любое
     сообщение из канала боту в личку и посмотрите `chat.id`, либо используйте
     @userinfobot / метод `getUpdates`. Ссылка-приглашение `t.me/+I1BEmUeJyE1kMmQy`
     сама по себе ID не содержит — его надо получить одним из способов выше.
4. Введите бота в приватный чат канала (https://t.me/+I1BEmUeJyE1kMmQy) — иначе он
   не увидит сообщения там. Отключите Privacy Mode у бота через @BotFather
   (`/setprivacy` -> Disable), чтобы бот видел сообщения с упоминанием в группе.

## Пример использования
В чате канала:
> @your_bot https://habr.com/ru/articles/XXXX/

Бот опубликует в канал: картинку (og:image), жирное название статьи и ссылку
«Читать полностью», а в чате ответит ссылкой на получившийся пост.
